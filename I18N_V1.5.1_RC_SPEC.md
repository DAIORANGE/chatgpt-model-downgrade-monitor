# v1.5.1 RC — Bilingual UI / 双语界面规范

Target branch: `v1.5.1-rc`

Goal: turn the current Chinese-first userscript UI into a complete switchable Chinese/English interface without changing observer semantics, evidence logic, PoW calculations, request interception, persistence semantics, or privacy behavior.

## 1. Language modes

Add a persisted setting:

```js
language: "auto" // "auto" | "zh-CN" | "en"
```

Rules:

- `auto`: use `navigator.language` / `navigator.languages`; Chinese locales -> `zh-CN`, everything else -> `en`.
- explicit `zh-CN` or `en` overrides browser locale.
- language changes apply immediately after saving/selecting; no page reload required.
- existing users with no language field migrate safely to `auto`.
- changing language must not clear or rewrite history, PoW history, network labels, geometry, theme, or other settings.

## 2. UI architecture

Use a central translation layer rather than duplicated templates or DOM text-replacement hacks.

Recommended shape:

```js
const I18N = {
  "zh-CN": { ... },
  en: { ... }
};

function currentLanguage() { ... }
function t(key, vars = {}) { ... }
```

`t()` must support placeholders such as `{model}`, `{count}`, `{captured}`, `{total}`, `{source}`, `{value}`.

Do not localize raw technical values such as model slugs, IDs, URL paths, JSON keys, timestamps, `resolved_model_slug`, `server_ste_metadata.model_slug`, raw PoW values, or copied diagnostic JSON field names unless they are already human-facing labels.

## 3. Coverage: translate ALL user-facing UI

English mode must not leave ordinary visible Chinese labels behind, except the Chinese project nickname/logo when intentionally shown as branding.

Coverage includes at minimum:

- header / brand subtitle / buttons / tooltips;
- tabs: Current / Archive / Network / Settings;
- floating monitor and hover text;
- status pills and verdict text;
- model-flow labels and state explanations;
- Requested / Assistant / Resolved / Server route evidence labels;
- evidence completeness and evidence ledger;
- trigger-condition explanations and dynamic reason text;
- prompt/reply preview labels;
- archive empty states and statistics;
- PoW chart axes, summaries, tooltips, node-link status, hover details, empty states;
- browser RTT/downlink wording;
- network label UI and defaults;
- settings groups, toggles, descriptions, selects, buttons, test/preview actions;
- theme selector labels where appropriate;
- alert/toast/title-flash visible strings;
- concept/info cards opened by `ⓘ`;
- copy-diagnostics success/failure feedback;
- generic states such as captured / waiting / not observed / unknown / none / unavailable;
- any confirmation/error text shown to the user.

- 调用模型 -> Requested model
- 应答模型 -> Assistant model
- 服务器确认模型 -> Resolved model
- 服务器路由 -> Server route
- 模型一致 -> Models match
- 模型不一致 -> Model mismatch
- 路由证据冲突 -> Routing evidence conflict
- 证据未完整 -> Incomplete evidence
- 核心对比 -> Core comparison
- 总证据 -> Total evidence
- 技术证据 -> Technical evidence
- 已捕获 -> Captured
- 等待中 -> Waiting
- 未观测到 -> Not observed
- 当前 -> Current
- 档案 -> Archive
- 网络 -> Network

- 模型档案 · 一问一答一张卡 -> Model archive · one card per turn

Status wording should stay factual and avoid stronger claims than the Chinese version.

## 7. Dynamic evidence semantics must not change

Localization must NOT alter:

- requested/assistant/resolved/server-route extraction;
- TurnAggregator correlation or dedupe;
- verdict calculation;
- evidence completeness calculation;
- PoW parsing, work estimate, link state, semanticSnapshot hydration;
- observer-only / fail-open behavior;
- Fetch/SSE/WebSocket transport handling;
- local-storage data schema except additive `language` setting.

Translation is presentation-only.

## 8. Diagnostics and stored history

- Historical entries remain language-neutral data.
- Rendering should localize them at display time.
- Do not rewrite old history just to translate labels.
- Copied diagnostics may keep stable machine-readable field names; human-readable headings/messages can follow the selected UI language.

## 9. Layout / visual regression

English text is often longer than Chinese. Check:

- tabs do not clip;
- settings rows wrap cleanly;
- model-flow center column remains centered;
- floating monitor remains compact;
- buttons do not overflow;
- PoW tooltips stay within bounds;
- info/concept cards remain readable;
- responsive layout still works at <=720px.

Do not reduce fonts merely to make English fit. Prefer wrapping, width adjustment, or concise wording.
